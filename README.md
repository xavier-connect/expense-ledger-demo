# Expense Ledger — Investor Demo

This is a **read-only snapshot** of a Hyperledger Fabric-based expense
ledger, built for a real estate investment company in Oman to give investors
transparent visibility into how project funds are spent.

This page shows a periodically-published copy of the
ledger, exported from a private Hyperledger Fabric network. Data shown here
is for demonstration purposes only.

## How it works

- Expenses are recorded on a permissioned Hyperledger Fabric blockchain by an
  authorized finance officer identity.
- The ledger is append-only: entries can never be edited or deleted, only
  corrected via an explicit, auditable reversal.
- Investor and auditor identities have read-only access to query the ledger.
- This site is generated by periodically exporting the current ledger state
  (readable only by an investor-role identity) to a static JSON file, which
  this page renders.

## Pages

- `index.html` — all recorded expenses, with running totals
- `expense.html?id=<id>` — detail view for a single expense, including its
  full on-chain write history (proof it has never been altered)
- `blockchain.html` — current block height and hash chain status
